# E-Commerce Sales & Returns Analytics

## Project Overview
An end-to-end data analytics project focused on analyzing e-commerce sales performance, profitability, product categories, and customer return behavior using SQL and Power BI.

## Business Objectives
- Analyze overall sales and profit performance.
- Evaluate profit margins and return rates.
- Identify top-performing product categories.
- Compare sales across customer segments.
- Explore performance across regions and time periods.

## Tools & Technologies
- **SQL:** Data analysis and business queries
- **Power BI:** Interactive dashboard development
- **DAX:** KPI calculations and measures
- **Power Query:** Data preparation, if applicable

## Dashboard Highlights
- Total Net Sales
- Total Profit
- Profit Margin
- Return Rate
- Sales and Profit Trends
- Sales by Product Category
- Sales by Customer Segment
- Region and Order Date filters
